# Criar uma trilha

Uma trilha é um assunto. "Testes em React", "Japonês básico" ou "Harmonia no violão" são trilhas. Se o assunto for grande demais para caber num mapa que você consiga ler, ele provavelmente são duas trilhas.

## Como fazer

1. Em **Minhas trilhas**, clique em **Nova trilha**.
2. Em **O que você está aprendendo?**, escreva o nome do assunto. Esse nome vira a **página principal**, o centro do mapa.
3. Confira o **Projeto** e clique em **Criar trilha**. A página principal abre, pronta para você escrever.

Toda trilha começa como **Estudo**: com uma página só, ainda não há o que seguir. Quando ela tiver páginas, você pode transformá-la em trilha guiada (veja [[Estudo ou trilha guiada]]).

## Um exemplo

Quem estuda testes em React cria a trilha "Testes em React" e escreve na página principal:

> Quero testar componentes pelo que a pessoa vê, sem testar detalhes de implementação.
>
> - `[[Por que testar comportamento]]`
> - `[[React Testing Library]]`
> - `[[Simular a API com MSW]]`

Cada `[[link]]` é uma página que ainda não existe. Ela aparece no mapa, apagada, esperando ser aberta. Abrir o link cria a página.

## Experimente

Crie uma trilha sobre algo que você está aprendendo agora. Na página principal, escreva uma frase sobre o seu objetivo e três tópicos como links. Ainda não abra nenhum: só olhe o mapa crescer.

## Cuidado com

Não precisa planejar a trilha inteira antes. O mapa se ajusta conforme você escreve: comece com o que sabe hoje e deixe os links puxarem o resto. Como os links funcionam está em [[Links entre páginas]].

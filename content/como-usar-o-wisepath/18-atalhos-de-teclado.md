# Atalhos de teclado

| Onde | Teclas | Faz |
| --- | --- | --- |
| Qualquer lugar | ⌘P / Ctrl P | Buscar em todas as trilhas |
| Qualquer lugar | ⌘⇧Espaço / Ctrl+Shift+Espaço | Capturar para a Caixa de entrada |
| Mapa | ⌘K / Ctrl K | Buscar nesta trilha |
| Mapa | Tab, depois ← → ↑ ↓ e Home | Andar pelas páginas do mapa |
| Mapa | Enter ou Espaço | Abrir a página |
| Mapa e lista | N | Adicionar uma página que nasce da página em foco |
| Texto | `[[` | Escolher ou criar uma página para ligar |
| Texto | `/` | Comandos |
| Página aberta | Esc | Fechar |
| Vídeo | N | Pausar e escrever uma nota |
| Vídeo | Espaço ou K · ← → · F | Tocar e pausar · pular 5 s · tela cheia |

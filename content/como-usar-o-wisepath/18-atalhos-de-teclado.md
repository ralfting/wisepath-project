# Atalhos de teclado

Quem estuda com o WisePath aberto ao lado de um vídeo ou de um editor de código ganha muito tempo pelo teclado. Estes são os atalhos do dia a dia. No Windows e no Linux, troque ⌘ por Ctrl.

## Em qualquer lugar

| Teclas | Faz |
| --- | --- |
| ⌘P | Buscar em todas as trilhas |
| ⌘⇧Espaço | Capturar para a Caixa de entrada |

## No mapa

| Teclas | Faz |
| --- | --- |
| ⌘K | Buscar nesta trilha |
| Tab, depois ← → ↑ ↓ e Home | Andar pelas páginas do mapa |
| Enter ou Espaço | Abrir a página |
| N | Criar uma página que nasce da página em foco |

## Escrevendo

| Teclas | Faz |
| --- | --- |
| `[[` | Escolher ou criar uma página para ligar |
| `/` | Comandos |
| ⌘K com texto selecionado | Transformar o texto em link |
| Esc | Fechar a página aberta ao lado do mapa |

## Num vídeo

| Teclas | Faz |
| --- | --- |
| N | Pausar e escrever uma nota |
| Espaço ou K | Tocar e pausar |
| ← → | Pular 5 segundos |
| F | Tela cheia, com as notas |

## Experimente

Numa trilha sua, abra uma página no mapa, feche com Esc e navegue pelas setas até a página principal sem tocar no mouse. Você terminou esta trilha: volte quando quiser rever algum ponto.

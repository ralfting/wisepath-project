# Projetos

Com o tempo, as trilhas se acumulam: trabalho, faculdade, hobbies. **Projetos** agrupam trilhas para a tela inicial continuar fácil de ler.

## Como funcionam

- Toda trilha está em um projeto. Toda conta já vem com o projeto padrão, **Geral**, que pode ser renomeado mas não excluído.
- **Novo projeto**, ao lado de **Nova trilha**, cria outro grupo. O **+** de um projeto cria uma trilha já dentro dele.
- Para mudar uma trilha de projeto, arraste o cartão até o outro grupo, ou use **Mover para** no menu do cartão. Se algo der errado ao salvar, ela volta para onde estava, e um aviso oferece **Desfazer**.
- Excluir um projeto não apaga as trilhas: elas voltam para o projeto padrão.

## Um exemplo

Quem estuda desenvolvimento frontend pode ter um projeto "Frontend" com "Testes em React", "Acessibilidade" e "CSS moderno", e outro projeto "Idiomas" com "Japonês básico". Com um projeto só, os cartões aparecem sem cabeçalho; com dois ou mais, cada projeto vira um grupo.

## Experimente

Crie um projeto com o nome de uma área da sua vida e mova uma trilha para ele arrastando o cartão.

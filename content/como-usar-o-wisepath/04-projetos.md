# Projetos

Projetos agrupam trilhas. Toda conta tem um projeto padrão, **Geral**, que pode ser renomeado mas não excluído.

- **Novo projeto**, ao lado de **Nova trilha**, cria outro grupo.
- Arraste o cartão de uma trilha para outro projeto, ou use **Mover para** no menu do cartão.
- Excluir um projeto não apaga as trilhas: elas voltam para o projeto padrão.

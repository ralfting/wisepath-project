# Como usar o WisePath

O WisePath é um caderno para estudar por conta própria. Cada assunto vira uma **trilha**: uma página central com o nome do assunto e outras páginas ligadas a ela por `[[links]]`. As ligações formam um mapa, e é por ele que você entende como as partes se conectam e volta ao que estudou meses depois.

Esta trilha é uma **trilha guiada**. Leia uma página por vez, marque **Já estudei** no fim de cada uma e use **Continuar estudando** para ir à próxima.

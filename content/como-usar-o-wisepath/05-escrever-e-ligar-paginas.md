# Escrever e ligar páginas

Escrever é o centro do WisePath. O mapa, o progresso e a busca vêm todos do que você escreve nas páginas. Esta parte mostra como escrever bem e como ligar as ideias.

## Como é o editor

O editor formata enquanto você digita: um `#` no começo da linha vira título, um `-` vira lista. Tudo é guardado em **Markdown**, um formato de texto simples que outros programas também abrem. Você não precisa saber Markdown para usar o WisePath; o **?** na barra do editor mostra o que ele entende, se tiver curiosidade.

## O que cabe numa página

Uma página é texto livre: a explicação com suas palavras, exemplos de código, uma tabela comparando opções, links para artigos, um vídeo com anotações. Uma boa regra é **uma página por ideia**. "React Testing Library" é uma página; "Consultas por papel" é outra, ligada à primeira.

# Comandos com barra

Para não decorar formatação, digite `/` em qualquer ponto do texto. Abre uma lista de comandos; continue digitando para filtrar e aperte Enter para escolher.

## O que dá para inserir

- **Títulos**, **listas** e **listas de tarefas**, para organizar o texto.
- **Citação**, para destacar um trecho de um livro ou artigo, com a fonte.
- **Tabela**, para comparar coisas lado a lado.
- **Bloco de código**, com cores de sintaxe e a linguagem escolhida no canto do bloco.
- **Vídeo**, para incorporar um vídeo do YouTube (veja [[Anotações em vídeos]]).
- **Página**, que pede um nome, cria o link e abre a página nova.
- **Item da Caixa de entrada**, que traz para o texto algo que você capturou antes (veja [[Caixa de entrada]]).

## Um exemplo

Comparando formas de encontrar elementos num teste, a pessoa digita `/tabela` e monta:

| Consulta | Quando usar |
| --- | --- |
| getByRole | quase sempre |
| getByLabelText | campos de formulário |
| getByTestId | último recurso |

Uma tabela também nasce escrevendo a linha de cabeçalho, como `| A | B |`, e apertando Enter.

## Experimente

Numa página sua, digite `/` e insira uma lista de tarefas com três coisas que você quer estudar sobre o assunto.

# Links entre páginas

Os links são o que transforma um monte de anotações num assunto que você entende. Cada link diz "esta ideia leva àquela".

## Como fazer

Digite `[[` no texto. Abre uma lista com as páginas da trilha: escolha uma, ou escreva um nome novo para criar a página. Também dá para escrever o link inteiro à mão, como `[[Consultas por papel]]`.

- Um link para uma página que ainda não existe aparece **tracejado**. Clique nele e a página é criada.
- No mapa, essas páginas ainda não criadas aparecem apagadas, como um lembrete do que falta escrever.
- Passe o mouse sobre um link para ver as primeiras linhas da outra página sem sair de onde está.

## Um exemplo

Na página "Simular a API com MSW", a pessoa escreve: "isso só funciona se o teste esperar a resposta: veja `[[Esperar elementos com findBy]]`". O link liga as duas ideias, e no mapa aparece uma seta entre elas.

## Experimente

Abra uma das páginas que você criou, escreva `[[` e crie um link para uma página nova. Clique no link tracejado e escreva duas frases na página que nasceu.

## Cuidado com

- Os títulos são únicos dentro da trilha, para que um link nunca fique ambíguo.
- Ao **renomear** uma página, os links para ela acompanham o novo nome.
- Ao **excluir** uma página, os links para ela viram texto comum.
- O primeiro link que alcança uma página decide onde ela fica no mapa. Veja em [[O mapa]].

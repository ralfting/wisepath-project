# Links entre páginas

Escreva `[[` e o nome de uma página para ligar a ela. Ao digitar `[[`, abre uma lista das páginas da trilha; um nome novo ali cria a página.

- Um link para uma página que ainda não existe aparece tracejado. Abra o link e a página é criada.
- No mapa, essas páginas ainda não criadas aparecem apagadas, esperando por você.
- Os títulos são únicos dentro da trilha, para que um link nunca fique ambíguo.
- Ao renomear uma página, os links para ela acompanham o novo nome.
- Ao excluir uma página, os links para ela viram texto comum.

O primeiro link que alcança uma página decide onde ela fica no mapa. Veja em [[O mapa]].

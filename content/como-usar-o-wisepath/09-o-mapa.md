# O mapa

O mapa é o assunto visto de cima. Ele não é guardado à parte: nasce dos links que você escreve, e muda sozinho quando você liga ou desliga uma página.

## Como ler

- A **página principal** fica no centro. Os ramos se abrem para a esquerda e para a direita, um nível por coluna.
- O **primeiro link** que alcança uma página faz dela um ramo da página que tem o link. Os outros links aparecem como **setas** finas, que ficam mais fortes na página aberta.
- As páginas que ainda não existem aparecem apagadas, depois das reais.
- A visão **Lista** mostra a mesma árvore como uma lista recuada. É o padrão no celular.

## Como usar

- Clique numa página para abri-la ao lado do mapa. **Expandir** mostra a página em tela cheia.
- Um **+** na borda de uma página (ou a tecla **N** com ela em foco) cria uma página que nasce dela, sem precisar abrir e escrever o link.
- **⌘K** (Ctrl K) busca nas páginas desta trilha e destaca o que encontrou no mapa.
- Pelo teclado: Tab entra no mapa, as setas seguem os ramos, Enter abre.

## Um exemplo

Na trilha "Testes em React", o mapa mostra "React Testing Library" com três ramos: "Consultas por papel", "Simular cliques com user-event" e "Esperar elementos com findBy". Uma seta liga "Esperar elementos com findBy" a "Simular a API com MSW", porque uma página cita a outra.

## Experimente

Abra o mapa de uma trilha sua, escolha uma página e use o **+** para criar dois ramos nela.

# O mapa

O mapa é uma leitura dos links: ele não é guardado à parte, nasce do que você escreve.

- A página central fica no meio, e os ramos se abrem para a esquerda e para a direita, um nível por coluna.
- O primeiro link que alcança uma página faz dela um ramo da página que tem o link. Os outros links aparecem como setas finas.
- Também dá para ver a trilha como uma **lista** recuada, que é o padrão no celular.
- Clique numa página para abri-la ao lado do mapa. **Expandir** a mostra em tela cheia.
- Um **+** na borda de uma página (ou a tecla **N**) adiciona uma página que nasce dela.

# Links da web

Um endereço da web sozinho na linha aparece com o ícone e o título do site. Passe o mouse sobre qualquer link para ver um cartão com a descrição; um clique no cartão abre o site em outra aba.

Um link com texto próprio, como `[documentação](https://exemplo.com)`, mostra o texto que você escreveu.

Um endereço do YouTube sozinho na linha vira um vídeo incorporado: veja [[Anotações em vídeos]].

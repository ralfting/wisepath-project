  <files>

  <action>
    Implement complete authentication logic:
    
    1. Add dependencies to apps/api/package.json:
       - @nestjs/passport, @nestjs/jwt, passport, passport-jwt
       - bcrypt, @types/bcrypt
    
    2. Implement apps/api/src/auth/auth.service.ts:
       - signup(dto: SignupDto):
         - Check if email exists (return 409 if yes)
         - Hash password with bcrypt (10 rounds)
         - Create user in database via Prisma
         - Return sanitized user (no password)
       - login(dto: LoginDto):
         - Find user by email
         - Compare password with bcrypt
         - Return user if valid, throw 401 if not
       - generateJwtToken(user): create JWT with payload { userId: user.id, email: user.email }
       - Inject PrismaService
    
    3. Update apps/api/src/auth/auth.controller.ts:
       - POST /signup:
         - Call authService.signup()
         - Generate JWT via authService.generateJwtToken()
         - Set httpOnly cookie: 'access_token', maxAge: 24h, httpOnly: true, secure: process.env.NODE_ENV === 'production', sameSite: 'lax'
         - Return { user } (not token - it's in cookie)
       - POST /login:
         - Call authService.login()
         - Generate JWT
         - Set httpOnly cookie (same settings)
         - Return { user }
       - POST /logout:
         - Clear cookie: res.clearCookie('access_token')
         - Return { message: 'Logged out' }
       - GET /me (authenticated):
         - Return current user from JWT
         - Use @UseGuards(JwtAuthGuard)
    
    4. Create apps/api/src/auth/jwt.strategy.ts:
       - Passport strategy extending PassportStrategy(Strategy)
       - Extract JWT from cookie (not Authorization header)
       - Validate payload and return user
    
    5. Update apps/api/src/auth/auth.module.ts:
       - Import JwtModule.register({ secret: process.env.JWT_SECRET, signOptions: { expiresIn: '24h' } })
       - Import PassportModule
       - Add JwtStrategy to providers
    
    Per user decisions: JWT in httpOnly cookies, 24h access token, bcrypt for passwords, NestJS Passport.
  </action>

    <automated>pnpm --filter @wisepath/api run build && pnpm --filter @wisepath/api run start:dev &amp; sleep 5 &amp;&amp; curl -X POST http://localhost:3001/api/auth/signup -H "Content-Type: application/json" -d '{"email":"test@example.com","password":"password123"}' | grep -q "user"</automated>
  </verify>
  <done>Signup creates user and returns JWT cookie, login validates credentials and returns JWT cookie, /me returns authenticated user</done>

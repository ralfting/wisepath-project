  <action>
    Add Google OAuth authentication:
    
    1. Add dependencies to apps/api/package.json:
       - passport-google-oauth20
       - @types/passport-google-oauth20
    
    2. Create apps/api/src/auth/strategies/google.strategy.ts:
       - Class extending PassportStrategy(Strategy, 'google')
       - Configure with:
         - clientID: process.env.GOOGLE_CLIENT_ID
         - clientSecret: process.env.GOOGLE_CLIENT_SECRET
         - callbackURL: '/api/auth/google/callback'
         - scope: ['email', 'profile']
       - validate() method:
         - Extract email, name, googleId from profile
         - Call authService.findOrCreateOAuthUser('google', googleId, email, name)
         - Return user
    
    3. Update apps/api/src/auth/auth.service.ts:
       - Add findOrCreateOAuthUser(provider, providerId, email, name):
         - Check if user exists with googleId (if provider is 'google')
         - If yes: return user
         - If no: check if user exists with email
         - If email exists: link OAuth (update googleId)
         - If email doesn't exist: create new user with googleId, email, name, password=null
         - Return user
       - Handle both 'google' and 'github' providers (use switch or if/else)
    
    4. Update apps/api/src/auth/auth.controller.ts:
       - GET /auth/google:
         - @UseGuards(AuthGuard('google'))
         - Initiates Google OAuth flow
       - GET /auth/google/callback:
         - @UseGuards(AuthGuard('google'))
         - Receives OAuth callback
         - Generate JWT from req.user
         - Set httpOnly cookie (same settings as login)
         - Redirect to http://localhost:3000/dashboard
    
    5. Update apps/api/src/auth/auth.module.ts:
       - Add GoogleStrategy to providers array
    
    Per user decisions: Google OAuth via passport-google-oauth20, JWT in httpOnly cookie.
